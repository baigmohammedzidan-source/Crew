As the name suggests its not a single but a “Multi-agentic system” made for resolving a crucial problem faced by the investors thats research.Reseaching a stock takes a lot of time more than what we expect.So  to make it easier for investors to understand a stocks stand in the market we make use of our agents:

Micro_Agent: This agent calculates the standing of the stock for few Hrs
Meso_Agent: This agent calculates the standing of the stock for few Days
Macro_Agent: This agent calculates the standing of the stock for Months
Meta_Agent: This agent calculates the standing of the stock for Years

These Agents give their answers individually as a “YES” or “NO” with 5-bullets points to justify their answer.

Review_Agent: Now as we said that you got 4 agents giving their own opinions but there can be a disagreement between then and it can create a confusion in your mind to clear that problem we created review agent which goes through what the above 4 agents have to say and then gives his verdict in a “YES” or “NO”.with a small summary explaining his standing.

Altro_Agent: This agent is there to give you more options and not get stuck with only 1 stock this provides you with more reliable stocks which might grab your attention.

Parallel_Agent:To make the working more efficient and less time consuming we run all the 4 agents parallely as they share no connection which each other and relay on there own research
  
Root_Agent:This is the actual head which manages everything it make the “Parallel_Agent” execute first as other agents need the data of this agents to execute so once this 4 agents work is completed the “Review_Agent” is booted and after that the final but never the less “Altro_Agent” is executed and the final answer is presented to you.
